# Demos and Examples

This folder contains demonstration scripts and examples that showcase bot functionality.

## Files

- **demo_achievement_command.py** - Demonstrates the new achievement detail command functionality
  - Shows how the command searches for achievements
  - Displays example bot responses for various inputs
  - Simulates user interactions with the achievement info system

## Usage

These demo scripts can be run independently to:
- Test functionality without running the full Discord bot
- See example outputs and behaviors
- Debug specific features in isolation
- Demonstrate features to users or developers

## Running Demos

```bash
python demos/demo_achievement_command.py
```

Note: Demo scripts may require the main bot modules to be in the Python path.
